# 大三上學習網站

[開啟學習網站](https://yieyu049-commits.github.io/course-study-2026/) · [編輯 Google 試算表索引](https://docs.google.com/spreadsheets/d/1a4xgISRky7-iW6RNMRKU75nqi3ltxTLPBsDBH8YIob0/edit)

用「學習日曆」選日期，查看當天課程、教師、主題及配對資料；也可切換「每週課程」或「資料書架」。點資料名稱開啟原檔，讀完勾選「已讀」；每堂課可另外標記「課程完成」。

## 目前收錄

2026/10/16 版本包含 13 門課、186 個課程時段、509 份資料：363 份可用、146 份待核對。其中 65 份來自 Moodle（63 份課堂講義、2 份補充）；61 份已配對至課程，形成 82 個課程關聯，另外 4 份保留在課程資料書架。份數包含不同版本及已標記的重複資料。

待核對資料預設隱藏，可在資料書架勾選「顯示待核對」查看；不會列為每日推薦閱讀。配對與使用限制可查看資料說明，考試範圍以本期教師公告為準。

## 更新索引，不必重新上傳網站

網站讀取原試算表中單獨發布的「網站同步」分頁。該分頁以公式彙整來源資料，並啟用自動重新發布；請修改來源分頁，勿覆寫同步分頁的公式。

| 要更新的內容 | 修改位置 |
| --- | --- |
| 課名、教師、課程說明 | 「課程總覽」 |
| 日期、每堂主題、教師、推薦資料 | 「逐堂對照」 |
| 資料名稱、網址、分類及使用狀態 | 「考古」「筆記」「課堂講義」「補充」的對應資料列 |
| 本期 Moodle 檔案及課程配對 | Moodle 索引分頁 |

請保留既有固定 ID：課程總覽 J 欄、逐堂對照 M 欄、資料 R 欄。調整列序、主題或網址時不要更換這些 ID，才能延續閱讀與完成記錄。修改既有資料 G 欄網址並保留 R 欄 ID，課程推薦會使用新網址。課程名稱須在各來源分頁保持一致；改課名時請一併更新逐堂對照及資料所屬課程。

Moodle 索引的 S 欄填逐堂對照 M 欄的固定 ID，多個 ID 以分號分隔；T 欄填 `YYYY-MM-DD` 日期，多個日期也以分號分隔，僅在 S 欄空白時依「日期＋課程」配對。S 欄有值但找不到對應時，不會猜測日期，資料仍留在書架。U 欄填「考古」「筆記」「課堂講義」或「補充」。沒有確認配對的資料可將 S、T 留白。

網站開啟時會同步，頁面顯示期間每 5 分鐘再檢查；回到頁面也會檢查（至少間隔 1 分鐘）。可隨時按「更新索引」重試。Google 發布版本可能延遲數分鐘，請以頁面同步狀態確認；格式錯誤或連線失敗時保留上次有效內容，沒有快取時使用網站內建資料。

**新增檔案到 Google Drive／Moodle 資料夾不會自動建立索引。** 仍需把檔案連結及配對資訊加入上述來源分頁；加入索引後網站即可自動更新。

## 進度、權限與離線使用

已讀、課程完成及收藏只儲存在目前瀏覽器，不寫回試算表，也不跨裝置同步。清除瀏覽資料、換瀏覽器或網站網址後，記錄可能不同；瀏覽器禁止儲存時只保留到目前頁面關閉。

公開的「網站同步」輸出含課程內容與資料連結；原試算表的編輯／分享權限及教材 Google Drive 權限未修改。網站沒有上傳教材原檔，開啟原檔仍需網路及對應的 Google 帳號權限。

下載 `index.html` 可在本機直接開啟，不需安裝套件。離線時可瀏覽內建或已快取的索引；線上網站首次開啟與 Google Drive 教材仍需網路。

## 網站維護

GitHub Pages 使用 `main` 分支的根目錄，保留 `index.html`、`.nojekyll` 及本說明。課程和資料更新只需修改試算表；修改網站介面或同步來源設定時，才需替換網站檔案。
