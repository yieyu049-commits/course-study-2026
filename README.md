# 大三上學習網站

**Google 登入後，經管理員核准即可使用。** 開啟 [學習網站](https://yieyu049-commits.github.io/course-study-2026/)；課程與教材在 [原始 Google 試算表索引](https://docs.google.com/spreadsheets/d/1a4xgISRky7-iW6RNMRKU75nqi3ltxTLPBsDBH8YIob0/edit)維護。

## 登入與學習

網站擁有者帳號 **yieyu049@gmail.com** 可直接登入使用。其他 Google 帳號首次登入時會建立「檢視者」申請，並通知擁有者；核准後按「重新確認狀態」即可查看課程與教材連結。若通知郵件暫時寄送失敗，申請仍會保留。

擁有者與授權管理員可從頁面「管理申請」或 [管理入口](https://yieyu049-commits.github.io/course-study-2026/#admin=1)核准一般申請、拒絕或撤銷一般使用者的網站權限。只有擁有者能把已核准帳號「授予管理權」或「取消管理權」；管理員不能授權其他管理員，也不能變更擁有者或其他管理員的存取狀態。要撤銷管理員的網站存取，擁有者須先取消其管理權。開啟郵件連結不會自動核准。

一般帳號沒有管理申請或原始索引維護入口；後端也會拒絕其管理操作。管理員可看到索引維護入口，但編輯試算表及管理 Google Drive 資料夾仍須由擁有者另外分享指定項目。

使用「學習日曆」查看當天課程、教師、主題及資料，也可切換「每週課程」或「資料書架」。教材可標記已讀、加入收藏，每堂課可標記完成。「待核對」資料預設隱藏，不會列入課堂推薦。

已讀、完成與收藏保存在各自的帳號，同一帳號可跨裝置同步；需要立即取得另一裝置的新進度時，按「更新索引」。更換帳號會清除上一帳號的畫面。舊版瀏覽器的匿名紀錄不會自動匯入任何帳號。失去存取權或無法確認帳號與資料時，內容會鎖定，沒有離線課程副本。

## 更新索引，不必重新上傳網站

請編輯原試算表的來源分頁；「網站同步」以公式彙整，請勿覆寫公式。受保護版本透過後端讀取該分頁，不使用公開 CSV。

| 要更新的內容 | 修改位置 | 保留的固定 ID |
| --- | --- | --- |
| 課名、教師、課程說明 | 「課程總覽」 | J 欄 |
| 日期、每堂主題、教師、推薦資料 | 「逐堂對照」 | M 欄 |
| 資料名稱、網址、使用狀態 | 「考古」「筆記」「課堂講義」「補充」對應列 | R 欄 |
| Moodle 教材與課程配對 | 「Moodle教材」 | R 欄 |
| 來源類型、署名／提供者、標籤依據 | 上述五個教材分頁的 V、W、X 欄 | R 欄 |
| 教材原學年度、學期 | 上述五個教材分頁的 L、M 欄 | R 欄 |

資料卡與日曆會顯示來源標籤；資料書架可依來源類型、署名／來源集合、教材學年篩選。V 欄可選學長姐、同學、學生整理、Moodle、原始分享資料或待補；W 欄只填已確認的署名或提供者，未知可留空；X 欄記錄判斷依據。P 欄保留原始來源集合，不把來源帳號直接當成作者。

L 欄填原教材學年（例如 `113`），M 欄填原教材學期；無法確認填「未註明」。Moodle 資料夾的收錄學期不代表教材製作學年，請把收錄資訊記於 X 欄。所有標籤依 R 欄固定 ID 自動同步，請勿覆寫「網站同步」A2 與 W2 的公式。這些來源標籤僅提供核准使用者閱讀，一般使用者不能修改。

調整列序、主題或網址時，請保留既有固定 ID，才能延續進度。新增列也請填入不重複的固定 ID：以英文字母或數字開頭，可使用英數字、底線、連字號、句點或冒號，最長 128 個字元，例如 `lesson-20261018-01`。請勿複製其他列的 ID。

修改資料 G 欄網址時保留 R 欄 ID；若該資料也填在「逐堂對照」的推薦連結，請一併確認該連結指向正確的新檔案。課名須在各分頁一致；改課名時，一併更新逐堂對照及資料所屬課程。

「Moodle教材」分頁的配對欄位：

- **S 欄**：填「逐堂對照」M 欄的課堂 ID，多個以分號分隔。
- **T 欄**：填 `YYYY-MM-DD` 日期，多個以分號分隔；只有 S 欄空白時，才依「日期＋課程」配對。
- **U 欄**：填「考古」「筆記」「課堂講義」或「補充」。

S 欄有值卻找不到課堂時，教材會留在書架，不會猜測日期。尚未確認配對的資料可將 S、T 留白。新增 Google Drive／Moodle 資料夾檔案仍須加入索引，網站不會自動掃描資料夾。

進入網站時會同步；頁面顯示期間每五分鐘更新，切回頁面時也會檢查（至少間隔一分鐘）。可按「更新索引」立即重試。課程、教材及連結更新只需修改試算表；網站介面或服務設定變更才需要重新部署。

## 管理與權限

GitHub Pages 使用 `main` 分支根目錄。Google 登入由 Firebase Authentication 處理；課程索引、帳號核准與個人進度由 Google Apps Script 後端提供，每次讀取或儲存都會確認帳號權限。部署檔不包含課程與教材資料。

管理員應保持帳號／進度資料庫私人。來源試算表不需「發布到網路」，也不應重新公開舊 CSV 或將含課程資料的舊版靜態網頁上傳。

一般檢視者只能讀取課程與教材連結，並更新自己的已讀、完成與收藏；不能編輯或刪除課程教材、審核他人或管理分享。擁有者由固定信箱辨識，授權管理員由後端保存的 UID 與已驗證信箱共同辨識，不由申請者選擇。角色變更會在下一次請求生效；頁面重新確認權限時會更新管理入口。所有角色的學習進度均按各自帳號保存。

網站核准或授予管理權不會變更 Google Drive 原檔權限；開啟教材仍需原檔允許的帳號。一般使用者預設只申請指定範圍的 Drive「檢視者」；擁有者可另外授予指定管理員教材資料夾或來源索引的「編輯者」。不分享私人帳號／進度資料庫及 Apps Script 專案。網站權限與 Drive 分享分開管理，取消網站管理權或存取權時，也須另行檢查並調整 Drive 分享。

Google 原生介面仍可能顯示申請更高權限的選項，送出申請不會自動獲准。網站管理員不會自動取得 GitHub、Firebase 或後端專案的權限。存取控制無法收回他人已下載，或從過往公開版本與歷史紀錄取得的內容。
