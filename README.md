# 大三上每週學習網站

依照本學期課程清單，按每週授課主題查找考古、筆記、課堂講義及補充資料的靜態網站。

## 收錄範圍

- 13 門課、18 週、186 個課程時段。
- 298 份可用資料及 146 份待核對資料；待核對資料預設隱藏。
- 每堂課列出建議先讀的資料、教師及使用提醒，可依課程、類型及關鍵字篩選。
- 份數包含不同版本與已標記的重複資料。

## 使用方式

開啟網站後選擇週次，點選資料名稱即可前往原始 Google Drive 檔案。也可切換「資料書架」搜尋全學期資料、收藏資料或標記課程完成。

網站是一份靜態資料快照，不會自動同步原始 Google 試算表或最新課程公告。請以本期教師公告為準。

網站只包含索引與原檔連結，未包含原始教材檔案。開啟 Google Drive 原檔需要網路、登入適當的 Google 帳號，並具備該檔案的存取權限；網站公開不會改變原檔的分享權限。

完成與收藏記錄僅儲存在目前瀏覽器，沒有上傳到 GitHub 或其他服務。換瀏覽器、清除瀏覽資料或改變網站網址後，記錄可能不同；瀏覽器不允許儲存時，記錄僅暫存於目前頁面。

## 本機開啟

直接使用現代瀏覽器開啟 `index.html`，不需安裝套件或啟動伺服器。介面及索引可離線瀏覽，原始資料仍須連網開啟。

## 部署至 GitHub Pages

1. 將此資料夾內的 `index.html`、`.nojekyll` 與 `README.md` 放入 GitHub 儲存庫根目錄。
2. 在儲存庫的 **Settings → Pages**，將來源設為 **Deploy from a branch**。
3. 選擇 **main** 分支與 **/ (root)** 資料夾並儲存。
4. 等待 GitHub Pages 部署完成，再開啟設定頁顯示的網站網址。

此網站沒有建置步驟、外部資產相依或後端服務。更新索引時，重新產生並替換 `index.html` 即可。
